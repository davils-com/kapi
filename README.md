# kapi

The API toolkit of Davils for Kotlin: strict OpenAPI and AsyncAPI documents, JSON Schema 2020-12, and typed clients,
servers, models, mocks, webhooks and WebSocket channels generated on top of Ktor. Built for enterprise and critical
infrastructure, published under the Apache License 2.0.

kapi is under construction; the modules and their use are described here as they land.
